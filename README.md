# Safe Steps – Road Safety Awareness Project

Safe Steps is a school-based road safety awareness campaign aimed at improving learner safety around **Hoërskool Jan Viljoen**.

The project combines **data collection, analysis, awareness campaigns, practical solutions, and community engagement** to address unsafe road behaviour and environmental risks around the school.

**Website:** https://safestepsroadsafety.netlify.app/

---

## 🚀 Features

* Survey data collection and analysis
* Visual graphs showing key findings
* Problem analysis based on real learner data
* Structured solutions and action plans
* Road safety awareness campaigns
* Fundraising strategies and budgeting
* Campaign gallery and team showcase
* Project achievements and progress tracking
* Contact and communication links
* Responsive web design
* Dark mode support
* Interactive JavaScript features
* Countdown functionality for upcoming events

## 📊 Research & Data

Safe Steps uses learner research to identify and understand road-safety concerns around the school.

Research methods include:

* Learner surveys
* Data analysis
* Visual graphs
* Learner feedback
* Follow-up interviews

The follow-up interviews are designed to compare learner perceptions **before and after Safe Steps interventions** and help evaluate changes in road-safety awareness.
